# Jewellery online store

Проект содержит исходный HTML-макет и миграцию на Angular 19.

## Что уже сделано

- Историческая версия (HTML/Gulp) сохранена в корне репозитория.
- Добавлено Angular 19 приложение в `angular-app/`.
- Подключена runtime-локализация интерфейса: `ru`, `en`, `es`.
- Реализованы роуты-страницы:
  - `/` — главная
  - `/catalog` — каталог
  - `/login` — вход
- Добавлены стартовые секции, приближенные к бизнес-структуре legacy:
  - hero + категории на главной
  - sidebar фильтров + карточки товаров в каталоге
  - форма входа с доп. действиями на странице логина

## Запуск Angular-версии

```bash
cd angular-app
npm install
npm start
```
