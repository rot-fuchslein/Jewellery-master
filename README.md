# Jewellery online store

Проект содержит исходный HTML-макет и старт миграции на Angular 19.

## Что добавлено

- Каталог исходных файлов исторической версии (HTML/Gulp) в корне репозитория.
- Новый Angular 19 каркас в `angular-app/`.
- Runtime-локализация интерфейса на:
  - русский (`ru`)
  - английский (`en`)
  - испанский (`es`)

## Запуск Angular-версии

```bash
cd angular-app
npm install
npm start
```

## Следующие шаги миграции

1. Перенос страниц `index.html`, `catalog.html`, `login.html` в Angular-роуты.
2. Разбиение layout на переиспользуемые компоненты.
3. Подключение API и состояния корзины.
